# 实景拼贴 · Gathered Scenes Zine v1.3

一个把真实照片转换为纸张质感拼贴海报的 Codex Skill。它以真实摄影为视觉锚点，通过源自照片的简化插画、结构性色彩、主动负空间和手撕纤维边界，形成安静、平面、非商业化的纸刊视觉。

## 原始设计核心

原版建立了以下主要视觉原则：

- **真景为锚：**保留照片的场景身份、关键空间关系和真实摄影质感。
- **插画成场：**用扩大后的抽象插画场解释照片，而不是描摹整张照片。
- **色彩成结构：**只增加一种高饱和印刷色，并让它承担平衡、连接或引导视线的作用。
- **撕纸成界：**摄影与纸面的主要交接使用清晰可见、平面扫描式的手撕纤维边缘。
- **纸面会呼吸：**保留大量负空间，压缩植物、建筑纹理和重复细节。
- **微型文字：**文字保持短小、纸面化，并从属于照片和插画。

## 本地调整

本地修改由 **啊贵** 根据实际生成结果提出，Codex 协助写入并完成校验。修改日期为 **2026-08-09**。

### 1. 默认保持原照片比例

原版默认使用竖版 `3:5`，只有用户明确要求时才切换比例。

本地版本改为：

- 生成前读取源照片尺寸和宽高比；
- 默认沿用原照片比例；
- 只有用户明确指定其他比例时才覆盖；
- 在决策优先级、提示词编译器、生成流程、严格禁止项和质量门槛中重复落实这项规则。

例如，`3:2` 横图默认生成 `3:2` 横版海报，而不再自动变成 `3:5` 竖版。

### 2. 辅助碎片必须成为原照片的低细节视觉回声

原版已经要求插画和色彩源于照片，但实际生成时仍可能出现与场景关系较弱的圆点、几何块、标签或装饰纸片。

本地版本增加了更严格的约束：

- 每个辅助碎片都必须对应原图中可明确指出的区域、轮廓、轴线、节奏、空隙、剪影、材质、阴影、色块或空间关系；
- 只保留来源对象的方向、比例、间距或明暗关系，删除大部分描述性细节；
- 在构图允许时，让碎片与来源区域对齐、相接、延续、重叠或从撕纸边界中生长；
- 生成前为每个计划中的辅助碎片指定一个源图对应物；
- 无法用一句短语说明来源的碎片必须删除；
- 禁止为了“看起来更有设计感”而加入通用圆形、矩形、圆点、箭头、印章、标签、植物标记或无来源纸片。

典型对应关系包括：

| 原照片元素 | 允许的低细节回声 |
|---|---|
| 建筑窗格 | 稀疏的重复方格或竖向节奏 |
| 道路、走廊 | 延伸到纸面的汇聚线或断裂轴线 |
| 海岸线、地平线 | 水平断线、低密度半色调带 |
| 天空、水面 | 与照片边界相接的低信息色面 |
| 树冠、树林 | 一两个合并后的剪影块和少量枝条动作 |
| 灯带、窗光 | 与源位置一致的稀疏印刷节奏 |

### 3. 新增专门的定向纠错

本地版本增加了“无关辅助碎片”失败类型：

> 删除所有没有明确可见来源的碎片，只重建与对应照片区域或撕纸边界对齐、接触、延续、重叠或长出的低细节回声。

这让自动重生成可以专门修正“装饰与照片无关”的问题，而不必重做整套风格。

### 4. 扩展严格禁止项和质量门槛

新增检查包括：

- 未经明确要求不得改变原图比例；
- 每个辅助碎片必须能追溯到一个可命名的源图元素；
- 碎片必须表现为纸面上的简化回声，而非孤立装饰；
- 最终检查时需要确认其与来源对象存在对齐、连接、延续、重叠或生长关系。

## 未改变的内容

- 默认输出图片与简短创作说明；
- 当前对话前两次成功生成后的作者署名提示。

## 使用方式

提供一张照片并调用：

```text
用 $scenes-gathered-zine-v1-3 把这张照片做成一张拾景纸刊海报。
```

默认行为：

1. 检查照片内容、尺寸和比例；
2. 保持原照片比例；
3. 保留场景身份和关键空间关系；
4. 从照片中提取插画、辅助碎片和结构色；
5. 生成具有手撕纤维边界和主动负空间的纸刊海报；
6. 在正常尺寸和缩略图下检查结果，必要时定向修正一次。

用户仍可覆盖默认设置，例如指定竖版、方形、中文文字或具体文案。
